## Scope and limitations

V6 adds reusable descriptive analytics over historical synthetic observations, a Plotly map of simulated points, and deterministic what-if comparisons using the existing predictor, capacity planner, experiment database, and report routes. Demand predictions remain fixed across changes to capacity assumptions. Historical `connections_next_hour` is an observed synthetic target, not a model prediction. Capacity and utilization values are illustrative connection-count proxies. Nothing in this release validates real public WiFi demand, infrastructure placement, forecast quality, network performance, or causal improvements in Tunja.

Release readiness requires the complete Python suite, Ruff, Black, dashboard/API checks, Compose validation, required container checks (local or verified remote CI), report and persistence verification, reviewed bilingual docs, safe Git push, and a tag/release on the exact verified commit. Update this record only with observed command output and verified remote evidence.
