**Status: implementation candidate; not a stable release.** Intended project release label: V5.0.0. Python package and Docker image candidate: `0.5.0`. No tag or GitHub Release is asserted in this record. Update this file only with evidence actually observed.

## Scope delivered locally

- Added a reusable deterministic capacity-planning service for simulated connection counts with explicit units, zero-capacity handling, bounded greedy allocation, budget conservation, and stable tie breaking.
- Added transactional SQLite experiment persistence, schema versioning, stable IDs, UTC timestamps, paginated list/retrieve API, scenario execution across synthetic zones, and JSON/Markdown reports with model traceability.
- Added a dashboard workflow to save a single-zone experiment from the existing scenario prediction flow and an Experiment History page with JSON download.
- Added a Compose-managed persistent volume for experiment data.
- Added a date-filtered geospatial zone summary of historical synthetic observations and bilingual assistant access to saved experiment details/comparisons.
- Existing classifier/regressor implementations and historical synthetic evaluations are retained; no claims of real-world predictive validity are made.
