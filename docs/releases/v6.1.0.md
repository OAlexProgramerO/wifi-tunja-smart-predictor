## Scope

V6.1 adds deterministic bounded integer allocation optimization to the existing scenario workbench. It uses the current regressor, API, SQLite experiment records, and report routes. The optimization objectives concern synthetic predicted connection deficits only. The work does not change model training or artifacts, dataset generation, prediction definitions, geospatial analysis, or dashboard navigation sections.
