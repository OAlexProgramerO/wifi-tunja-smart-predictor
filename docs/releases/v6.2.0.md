## Scope and interpretation

V6.2 adds deterministic, bounded one-zone-at-a-time synthetic demand sensitivity and a separate budget sweep for saved V6.1 optimization runs. It reports original and reoptimized objectives under each tested assumption, explicit hard-minimum budget shortfall, per-zone allocation stability, and partial/search-limited status. It reuses the V6.1 optimizer, existing SQLite records, API history/report routes, and Scenario Workbench. The synthetic analyses are not real-world demand validation, probabilities, or operational reliability estimates.
