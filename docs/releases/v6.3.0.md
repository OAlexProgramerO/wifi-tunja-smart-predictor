## Delivered scope

V6.3.0 adds a bounded temporal evaluation service that fits cloned classifier and regressor pipelines using strictly earlier rows, summarizes window metric changes, and measures selected numerical or categorical feature-distribution differences. `POST /evaluation/temporal` returns a versioned report with dataset and model artifact fingerprints; the Model Performance section displays results and provides JSON and Markdown downloads. It does not change model selection, model artifacts, or prediction behavior.
