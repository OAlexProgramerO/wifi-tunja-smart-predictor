# WiFi Tunja Smart Predictor V4.1.0 — implementation and validation record

**Release status: not published.** This record documents the V4.1.0 implementation candidate and the evidence checked on 2026-10-17. Release acceptance remains blocked by missing Docker runtime and GitHub Actions evidence. No V4.1.0 version bump, tag, or GitHub Release has been made.

All datasets, model artifacts, and metrics in this repository are synthetic. These software checks do not validate forecasts against actual public WiFi demand or infrastructure in Tunja.

## Implemented changes

The implementation is already integrated into `main` at commit `8bc5c03` (with artifact-validation changes in `8e2aa1c`). It adds focused reliability coverage while preserving the existing architecture:

- Classifier model caching uses the artifact file signature so replacing the file causes a reload.
- Readiness and model information validate the classifier's `LOW`/`HIGH` labels and the classifier/regressor metadata contracts.
- Runtime initialization validates an already-complete model bundle and refuses to overwrite persistent resources when artifacts are invalid.
- Prediction failure logs retain bounded stack-frame diagnostics while HTTP errors remain sanitized.
- Regression tests cover model replacement, invalid/malformed metadata and artifacts, incompatible labels, initialization safety, model information, and sanitized failures.

No classifier or regressor algorithm, temporal evaluation strategy, model metric, dataset, dashboard section, or external service was changed for this candidate.
