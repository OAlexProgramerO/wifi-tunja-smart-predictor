## Scope and changes

- Compatible experiment comparisons retain their prior HTTP status and fields, with additive interpretation fields. Shared-zone comparisons are technically compatible but limited synthetic comparisons. No shared zone IDs yields `comparison_status: no_shared_zones`, `scientific_comparability: not_assessable`, and an explicit reason; no zone deltas are fabricated.
- Experiment History loads 25 records per page using the existing `limit`/`offset` API and distinguishes an empty later page from an empty history.
- No database schema, persisted experiment format, model artifact, prediction algorithm, or API route changed.

## Known limitations and scientific scope

- Data, access points, locations, history, model predictions, and scenario metrics are synthetic. Metrics do not demonstrate forecast accuracy on real public WiFi demand in Tunja.
- Shared-zone comparison means matching stored time, dataset, and model fingerprints plus at least one shared zone ID. It does not establish causal validity or broader scientific equivalence.
- Model diagnostics, inference behavior, and assistant architecture are unchanged in this increment.
